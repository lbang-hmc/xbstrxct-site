Plain inline tags: #emergence and #representation.
Repeated tags: #representation #representation.
Nested tag: #mathematics/algebra.
Mixed case: #Topology.

Inline code `#not-a-tag-code` is not a tag.

A URL https://example.com/page#not-a-tag-url is not a tag.

Math $a \# b = |\#S|$ is not a tag, nor is display math:

$$
\#\{x \in X : \alpha(x) = 0\}
$$

Punctuation before a hash: (#not-a-tag-paren).

Numbers are not tags: #2024 and #1.

[An anchor link](#heading-anchor) is not a tag.

```c
#include <stdio.h>
// #not-a-tag-fence
```
